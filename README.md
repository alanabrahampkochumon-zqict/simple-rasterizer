# Scanline Rasterizer

A simple Scanline Rasterizer in React and TypeScript.

## How to Run

1. Clone the repository
   `git clone https://github.com/alanabrahampkochumon-zqict/simple-rasterizer.git`
2. Install the node packages
   `npm install`
3. Run the server
   `npm run dev`
